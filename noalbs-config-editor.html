    📡 OBS WebSocket How NOALBS talks to OBS Studio (OBS 28 or newer)
    Find these in OBS under Tools → WebSocket Server Settings. Connect to pick scenes, sources, profiles and scene collections from dropdowns instead of typing them.
    🗂️ Scene Collections Optional — lets you swap OBS profile + scene collection from chat with !collection
    🏷️ Config Name
    A display name for this config. It doesn't have to match any account.
    🎚️ Switcher Behavior
    Checks in a row before switching. Higher means fewer false switches but a slower reaction.
    🎬 Switching Scenes Must match your OBS scene names exactly (case-sensitive)
    Connect to OBS to pick these from a list of your scenes instead of typing them.
